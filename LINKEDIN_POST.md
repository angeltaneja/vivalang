🚀 Excited to announce my latest project: **VivaLang — AI Language Learning Platform**! 🌍🤖

Language learning apps often feel like either static flashcard tools or generic AI chatbots. I wanted to build something different — an experience centered on one core philosophy:

👉 **"Don't just study a language. Live it."**

VivaLang is a full-stack platform where users explore data-driven language worlds, practice real-time voice conversations with AI personas, roleplay realistic travel scenarios, and use an intelligent memory engine.

### 🌟 Key Highlights & Engineering Features:
🎙️ **Real-Time Voice AI Room**: Hands-free Speech-to-Text & Text-to-Speech audio pipeline with a 4-state visual waveform (Listening, Thinking, Speaking) and native AI personas (e.g., Paris florist, Berlin engineer).
📊 **Diagnostic Performance Reports**: Instant evaluation post-conversation measuring Speaking, Grammar, Vocabulary, and Pronunciation scores.
🌐 **Dynamic Immersion Mode**: One-click UI translation toggle that dynamically shifts navigation into target languages (French 🇫🇷, German 🇩🇪, Spanish 🇪🇸).
🧠 **Spaced Repetition Engine (SRS)**: SM-2 algorithm powering interactive 3D flip flashcards with mastery tracking (0-100%).
📝 **AI-Assisted Notes Workspace**: Markdown note editor connected to AI capabilities ("Explain Note", "Create Quiz", "Generate Flashcards").
⚡ **Data-Driven Curriculum**: CEFR-aligned (A1-C2) lessons with 5 exercise types & celebration mechanics.

---

### 💻 Built With:
- **Frontend**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4
- **AI Core**: Gemini 1.5 Flash API with structured JSON output + smart client fallback
- **Voice Engine**: Native Web Speech API (STT & TTS)
- **Database & ORM**: PostgreSQL / SQLite via Prisma ORM
- **UI & Micro-interactions**: Framer Motion, Lucide React, Canvas Confetti
